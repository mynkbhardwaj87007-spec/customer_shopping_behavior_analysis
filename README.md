# customer_shopping_behavior_analysis
An end-to-end data analysis project uncovering insights from 3,900 customer transactions across product categories — built with Python, PostgreSQL, and Power BI.

# 📌 Project Overview 
This project analyzes customer shopping behavior to answer real business questions around revenue, customer segments, discount strategy, and subscription growth. The full pipeline goes from raw data → Python EDA → SQL analysis → interactive Power BI dashboard.
Tools used: Python · PostgreSQL · Power BI
